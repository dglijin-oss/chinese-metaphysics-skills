> "择吉避凶，顺天应时。" ——《协纪辨方书》

## ⚠️ 铁律：先核对时间，再择日！

> "差之毫厘，谬以千里。" —— 时间一错，吉凶颠倒。

**每次择日前必须：**

1. **校正当前时间** — 以系统实时时间为准，不可用缓存或旧时间
2. **核实公历日期** — 年、月、日，一一确认
3. **核对农历日期** — 建除十二神以农历月为准
4. **验证节气** — 黄道黑道日以节气定月
5. **独立校验脚本输出** — 脚本若有 bug，人工复核

## 一、建除十二神

### 十二值日详解

| 值日 | 吉凶 | 宜 | 忌 |
|------|------|----|----|
| 建日 | 小吉 | 出行/上任 | 动土/开仓 |
| 除日 | 吉 | 扫除/求医/解除 | 婚嫁/上任 |
| 满日 | 吉 | 祭祀/祈福/婚嫁 | 服药/求医 |
| 平日 | 平 | 修补/平治 | 种植/动土 |
| 定日 | 吉 | 签约/订婚/安床 | 诉讼/出行 |
| 执日 | 吉 | 种植/捕捉 | 出行/搬家 |
| 破日 | 大凶 | 破除/拆迁 | 百事不宜 |
| 危日 | 小凶 | 祭祀/祈福 | 登高/行船 |
| 成日 | 大吉 | 婚嫁/开业/入学 | 诉讼/医疗 |
| 收日 | 吉 | 纳财/收债/入仓 | 出行/医疗 |
| 开日 | 大吉 | 开业/开张/动土 | 安葬 |
| 闭日 | 凶 | 修筑/闭塞 | 婚嫁/开业 |

### 推算方法

以月支起建，顺行十二日：
- 正月（寅月）：寅日起建，卯日除，辰日满...
- 二月（卯月）：卯日起建，辰日除，巳日满...

## 五、日课择日法

### 四柱日课

选择吉日需综合年月日时四柱：

1. **年柱**：不可冲太岁，宜合太岁
2. **月柱**：不可冲月令，宜得月令
3. **日柱**：不可冲主人生肖，宜与八字相合
4. **时柱**：宜生旺主事，不可空亡

### 日课吉凶判断

- **大吉日课**：四柱相生，无冲无破，吉神叠加
- **中吉日课**：四柱基本和谐，有吉神化解
- **小吉日课**：有小冲小破，但吉神多于凶煞
- **凶日日课**：四柱相冲，凶煞叠至，百事不宜

### 日课与主人生肖

择日必须避开冲主人生肖之日：
- 鼠年生人：避开午日（子午冲）
- 牛年生人：避开未日（丑未冲）
- 虎年生人：避开申日（寅申冲）
- 兔年生人：避开酉日（卯酉冲）
- 龙年生人：避开戌日（辰戌冲）
- 蛇年生人：避开亥日（巳亥冲）
- 马年生人：避开子日（子午冲）
- 羊年生人：避开丑日（丑未冲）
- 猴年生人：避开寅日（寅申冲）
- 鸡年生人：避开卯日（卯酉冲）
- 狗年生人：避开辰日（辰戌冲）
- 猪年生人：避开巳日（巳亥冲）

## 七、分类择日模板

### 婚嫁择日
- **首选**：天德/月德/成日/开日 + 三合/六合
- **避开**：三娘煞、杨公忌、红砂日、月破日
- **最佳月份**：春秋两季（二/三/八/九月）

### 开业择日
- **首选**：生气/天德/成日 + 紫白旺星时辰
- **避开**：岁破、月破、劫煞
- **最佳时辰**：辰时/巳时

### 动土择日
- **首选**：天德/成日/开日
- **避开**：土府/土禁/红砂/暗金煞
- **最佳方位**：当年大利方

### 出行择日
- **首选**：驿马/天德/开日
- **避开**：往亡/归忌/月煞
- **最佳时辰**：寅时/卯时
